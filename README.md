# K-Bird

A 3D remake of the classic DOS game **J-Bird**, built with **Three.js** and **React Three Fiber (R3F)**. Jump around the pyramid to hit all the cubes, collect points, and stay away from the tangerines!

## Gameplay

- **Numpad keys / WQEZC:** Move the bird
- The bird can also be moved by clicking/tapping the arrow buttons
- **Goal:** avoid falling down, dodge tangerines, collect points

## Tech Stack

- **3D & Graphics:** Three.js & React Three Fiber (R3F)
- **Utilities / Helpers:** @react-three/drei
- **Physics:** Rapier (R3F physics engine)
- **Frontend:** React
- **Dev Environment:** Vite

## How to Play Locally

1. Clone the repo:

```bash
git clone https://github.com/karinknutsson/k-bird.git
cd k-bird
```

2. Install dependencies:

```bash
npm install
```

3. Run the app:

```bash
npm run dev
```
